# Issue tracker

**Tracker:** GitHub Issues on https://github.com/rps321321/solpaper  
**PRs as a request surface:** no

## Wayfinding

- **Map:** issue labelled `wayfinder:map` (see #1) **and** in-repo mirror `docs/wayfinder/map.md` on `main`.
- **Tickets:** child/sub-issues with `wayfinder:research` | `prototype` | `grilling` | `task`.
- **Blocking:** GitHub issue dependencies + `Blocked by: #N` in the body.
- **In-repo index:** `docs/wayfinder/tickets.md`.

When resolving a wayfinder ticket: close the issue, update `docs/wayfinder/map.md` Decisions so far, update `tickets.md` if needed, commit research under `docs/research/`, and **push to GitHub**.

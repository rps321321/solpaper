# Asset and non-code license register

**Issue:** [#38](https://github.com/rps321321/solpaper/issues/38)  
**Policy:** [supply-chain.md](./supply-chain.md) § 1 Non-code assets

Record every non-code asset shipped or redistributed with Solpaper (icons, fonts, sample images, sounds, third-party docs). Code licensing is MIT via root `LICENSE`.

## Process

1. Before merging an asset, add a row here.  
2. Prefer MIT/Apache-2.0/CC0/OFL-1.1 (OFL needs human exception note in supply-chain § 8 if used).  
3. Deny GPL/AGPL/unknown/proprietary assets by default.  
4. Installer third-party notices (#39) must include attribution rows that require it.
